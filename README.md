# Analizing_house_pricing
This project is part of a Data Analysis course and focuses on identifying how different features influence house prices. The analysis includes data cleaning, exploratory data analysis, and interpretation of key factors affecting property value.

## Technologies 
- Pandas
- Numpy
- Scikit Learn
- Matplotlib
- Seaborn

## Dataset
https://www.kaggle.com/datasets/harlfoxem/housesalesprediction
